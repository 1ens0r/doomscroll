# DOOMSCROLL

Behavior-aware advertisement recommendation system using exploratory data analysis, behavioral feature engineering, and personalized ranking.

## Structure

- `eda/` — Exploratory data analysis and visualizations.
- `recommender-engine/` — Behavioral features, recommendation algorithms, and evaluation.

## Tech Stack

Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.
